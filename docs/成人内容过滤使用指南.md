# 🔒 成人内容过滤使用指南

## 📱 功能概述

DecoTV 默认过滤成人内容。要放开，必须**同时**满足两个条件：

1. 站长在后台 `站点配置` 中关闭 `启用成人内容过滤`。
2. 请求带有效的访问秘钥（URL 参数 `ak`），或者站长启用了“空秘钥”。

只满足其中一个时，内容仍然会被过滤。

> ⚠️ **旧方式已失效**：`?adult=1`、`?filter=off` 等参数不再单独生效；`/adult/` 路径前缀仍可访问，但不再放开成人内容。

---

## 🔑 站长配置

### 第 1 步：关闭总开关

进入后台 `站点配置`，关闭 `启用成人内容过滤`。也可以通过环境变量设置初始值：

```env
NEXT_PUBLIC_DISABLE_YELLOW_FILTER=true
```

### 第 2 步：生成访问秘钥

进入后台 `访问秘钥`，批量生成秘钥并发给需要的人。

- 一个秘钥可以给任意多人使用。
- 停用或删除后立即失效。
- 启用“空秘钥”后，不带秘钥或秘钥无效的请求也视为通过。此时所有用户都能看到成人内容，家庭共用的实例不要开启。

### 第 3 步：标记视频源

进入后台 `视频源管理`，把成人视频源标记为成人资源。过滤开启时，被标记的源会被隐藏。

---

## 🌐 Web 端用户

点击右上角用户菜单中的 `访问秘钥`，填写后保存。秘钥按设备保存在浏览器本地。

---

## 📺 TVBox 用户

### 默认地址（过滤成人内容）

```text
https://your-domain.com/api/tvbox/config
```

### 带访问秘钥（放开成人内容）

```text
https://your-domain.com/api/tvbox/config?ak=你的访问秘钥
```

站长未关闭总开关时，这个地址仍然会过滤。

### 其他参数

| 参数     | 值                           | 说明                                     |
| -------- | ---------------------------- | ---------------------------------------- |
| `ak`     | 访问秘钥                     | 配合后台总开关放开成人内容               |
| `proxy`  | `off`                        | 禁用智能搜索代理，直连原始 API（不推荐） |
| `strict` | `1`                          | 智能搜索使用严格匹配                     |
| `mode`   | `safe`、`min`、`yingshicang` | TVBox 配置兼容模式                       |

---

## 🎯 OrionTV 用户

API 地址默认只返回过滤后的内容：

```text
https://your-domain.com
```

OrionTV 可能不会把 API 地址中的查询参数传给后续请求，所以 `?ak=` 不一定生效。如果带秘钥后仍被过滤，只能由站长启用“空秘钥”，但这会对所有用户放开。

---

## ❓ 常见问题

### Q1: 带了秘钥还是看不到？

依次检查：

1. 后台 `启用成人内容过滤` 是否已关闭。
2. 秘钥是否已被停用或删除。
3. 客户端是否已刷新配置或重启。

### Q2: 如何知道当前是否在过滤？

查看接口响应头 `X-Adult-Filter`：`enabled` 表示正在过滤，`disabled` 表示已放开。

### Q3: 可以给不同用户设置不同策略吗？

可以。关闭总开关后，只把秘钥发给需要的人；不带秘钥的用户仍然看到过滤后的内容。前提是不要启用“空秘钥”。

---

## 📊 过滤机制说明

1. **源级别过滤**：被标记为成人资源的视频源会被隐藏。
2. **关键词过滤**：搜索结果会按 `src/lib/yellow.ts` 中的关键词过滤。
